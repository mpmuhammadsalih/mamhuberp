Operator checklist: batch & expiry (lots)

← Back to lot inquiry

Use this order for batch-tracked items. Session store / location is respected everywhere below.

  1. 1. Mark the item (once)

    On Batch / Expiry (lots), enter the item code and turn on Require batch + expiry on GRN; FEFO on sales, then Save.

    After this, GRN will expect batch and expiry for that item; sales will issue by FEFO (bins first, then unallocated stock).

    Open Batch / Expiry (lots)

  2. 2. Receive goods (GRN)

    Post a goods receipt from the purchase flow. For each batch line, enter batch number and expiry (and optional mfg). Posting creates a lot and adds quantity to unallocated lot balance.

    If the same batch already exists for that item/location, quantity is added to the same lot.

    GRN list / new receipt

  3. 3. Put away to bins (optional but recommended)

    On Batch / Expiry (lots), pick the warehouse site and click Apply. For a lot with Unalloc quantity, choose a bin, enter Qty, and click Go. That moves stock from unallocated into ITEM_LOT_BIN and updates BIN_STOCK for the same item and bin.

    Use Binned to see per-bin lot quantities. Bin stock screens stay item+bin; lot detail lives on this page.

    Put away (lot inquiry) Bin stock (warehouse) Storage / bin setup

  4. 4. Sell or pick (FEFO)

    On the sales invoice screen, add batch-tracked items as usual. The system issues by FEFO (earliest expiry first), taking from bins first, then unallocated lot balance.

    You do not have to type a lot on the sales line for normal sales.

    Sales invoice

  5. 5. Stock adjustment (if needed)

    On Stock adjustment, set store and quantities as today. For batch items, use Lot (opt.) to take from a specific lot on decreases; leave it blank to use FEFO. Increases post into a system adjustment lot when the item is batch-tracked.

    Stock adjustment

  6. 6. Purchase return to supplier

    On Purchase return, add lines and quantities. For batch items, you can enter Lot ID to return a specific lot; leave it blank to issue by FEFO. Set inventory location when the document requires it.

    Purchase return list New purchase return

Quick reference

  • Unallocated = lot quantity not yet in a bin (ITEM_LOT_BALANCE).
  • Binned = that lot in a specific storage bin (ITEM_LOT_BIN); Total = unalloc + binned.
  • BIN_STOCK is by item + bin; putaway keeps it in sync with lot bins for the same move.
  • Movements (and Mov on the lot grid) show IN/OUT and document references (GRN, sales, putaway, returns, etc.).
