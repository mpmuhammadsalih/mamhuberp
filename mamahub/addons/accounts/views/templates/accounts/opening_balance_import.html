Import opening balances

Upload a CSV or Excel file to post one balanced GL journal (e.g. cut-over from another system).

Opening balances in this app are normal GL history: the voucher you post here becomes the starting point for “opening” in account ledgers (anything dated before your first operating reports should use this voucher date, or the day you choose as go-live). Your file must use account codes that already exist in the chart. Each row: one of debit or credit (not both) per account; optional remarks, party_type, party_code (e.g. CUSTOMER + customer code for AR). If the file does not sum to a tie, set a balance account to post the difference (like “Opening balance equity”). Prefer Download Excel from Chart of Accounts — same layout as Chart of Accounts export — fill Debit/Credit, then upload.
