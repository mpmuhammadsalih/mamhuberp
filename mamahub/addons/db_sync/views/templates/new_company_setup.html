Clear business data

Disables foreign keys, TRUNCATEs tables in this schema, then re-enables constraints. Default: keeps LOGIN_USERS, ROLES, ROLE_PERMISSIONS, TENANT_DATABASES when the box below is checked. Table structures are unchanged. Optionally reset Oracle sequences and clear BILLNOTABLE so bill / GRN / LPO numbers can start from #1 again.

Default masters for new company setup are pre-filled. Edit only if you need a different skip list.

Execute: confirm below, type CLEAR ALL DATA, then submit.

Execute clear on target also runs UPDATE ITEMMASTER SET CURRENTSTOCK = 0, UPDATE ITEMALTERNATEUOMMAP SET CURRENTSTOCK = 0, and UPDATE CUSTOMER SET CURRENTCREDITAMOUNT = 0 (exact column names from your schema) on preserved master tables after truncate.
