(B) Clone full RFIM structure once (empty new Oracle user / tenant)

Not done in the browser. From the project folder, after creating the target Oracle user with quota: run python scripts/oracle_export_schema_ddl.py --profile rfim -o exports/rfim.sql, review SQL, then apply in SQL Developer; or use oracle_apply_schema_ddl.py with --execute --i-confirm. Full data clone: Data Pump (DBA).

(C) Long-term auto-DDL for all legacy RFIM tables

There is no in-app ORM that materializes hundreds of RFIM tables from Python. Use existing RFIM DB, or one-time clone (B).
