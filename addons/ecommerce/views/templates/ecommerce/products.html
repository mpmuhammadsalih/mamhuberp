Bulk product images

Choose an image folder (no ZIP needed) or a ZIP. One folder per product. Folder name is the barcode (example 1200000001035/1.jpg) or a file named 1200000001035-1.jpg, 1200000001035-2.jpg. A parent folder inside the ZIP is OK (example photos/1200000001035/1.jpg or photos/rattle-set/images/1.jpg). If the folder is not the barcode, use Excel column FolderName (example folder rattle-set, row FolderName = rattle-set). First photo is the main image, the rest go to the gallery. Optional in the same folder: description.txt, description_ar.txt, and specifications.txt (or product.json with those fields). Choose whether to keep an existing product photo or replace it. ZIP limit is 2 GB — a large file can take several minutes. Or use the Excel template with ItemCode/Barcode, FolderName, Description, DescriptionArabic, Specifications, ProductPageURL, and a pasted picture, ImageURL, or ImageFileName. Images are cropped to a square and resized to 800 × 800 px.
