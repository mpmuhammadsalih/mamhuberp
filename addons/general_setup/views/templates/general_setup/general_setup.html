General Setup

Organization-wide options that apply to all users and branches.

Customer request alerts

Currently: {% if customer_request_alert_poll_enabled %}Enabled{% else %}Disabled{% endif %}

When enabled, users with customer-creation access poll the server every 30 seconds for pending customer requests (badge, toast, and optional sound).

To disable polling and stop log lines like /ho/api/customer-request-pending-count, uncheck the box above and click Save. Open browser tabs stop polling within one cycle; new pages will not poll at all.

Transaction recording audit

Currently: {% if transaction_recording_enabled %}Enabled{% else %}Disabled{% endif %}

When enabled, transaction screens (Sales, GRN, PO, vouchers, etc.) capture field changes, before/after screenshots, and optional tab video via the Nexa Audit Recorder extension. Recordings are stored under /audit/recording and can be reviewed in Transaction Audit Viewer.

Uncheck to stop new recordings on all users and branches. Existing audit logs remain available in Reports → Transaction Audit Viewer. Users must refresh open transaction pages for the change to take effect.
